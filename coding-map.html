How this counts
  • Counts commits authored by the selected account on the default branch of RXSW repositories, mirroring how GitHub builds contribution graphs.
  • Commit day = the commit's committedDate (UTC date). Pushes, merges and rebases can shift a commit between days compared to your profile view.
  • It measures commits only. Issues, reviews and pull requests are not counted. If you are 99% commits, the totals will sit close to your profile graph.
  • Token needs read access to the org repositories. Classic PAT with the repo scope, or a fine-grained token with read-only Contents + Metadata for RXSWDevelopment. Create a classic token.
